# HTTP Methods - Postman Collection

This project demonstrates API testing using Postman by covering all major HTTP methods:

- GET
- POST
- PUT
- PATCH
- DELETE

## Tools & APIs Used
- Postman
- httpbin.org

## Features
- Request creation for all HTTP methods
- Automated test scripts using JavaScript
- Status code validation
- Response body validation


## Purpose
This project is created to demonstrate API testing skills, including request handling, assertions, and validation techniques using Postman.
